# Priyanshu Ganguly — Portfolio Website

A responsive personal portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — responsive layout, colors, typography, and animations
- `script.js` — mobile navigation, reveal animations, and email form
- `assets/FINAL_RESUME.pdf` — put your final CV PDF here

## Run locally
Open `index.html` in a browser. For development, you can also use VS Code Live Server.

## Before publishing
1. Copy your final CV to `assets/FINAL_RESUME.pdf` so the Download Resume button works.
2. Confirm all project URLs and replace any link that is outdated.
3. Replace the illustrative project artwork with screenshots of your actual projects.
4. Confirm the technology tags for each project; remove anything you did not use.
5. Add your LinkedIn profile URL if you want it shown.
6. Test the contact form. It opens the visitor's default email app; it does not send messages automatically. To collect messages without requiring an email app, connect a form backend/service.
7. Check all details, dates, and contact information before making the site public.

## Publish with GitHub Pages
1. Create a GitHub repository for the portfolio.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. In repository Settings → Pages, choose the branch and root folder, then save.
4. Wait for GitHub Pages to publish the site and open the generated URL.
